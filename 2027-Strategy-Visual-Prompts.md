## 11. Image Selection Checklist

Before using a generated image, the implementation or design agent must verify:

- The correct aspect ratio and minimum dimensions.
- No unauthorized logos, brands, properties, book covers or expert portraits.
- No casino clichés or operationally sensitive details.
- No accidental text where the prompt requires no text.
- Exact spelling where the prompt requires text.
- Sufficient negative space for responsive HTML copy.
- Adequate contrast after overlay.
- Useful crop at desktop and mobile breakpoints.
- The page remains understandable with the image removed.
- Alt text describes function, not decorative detail; use empty alt text for purely decorative backgrounds.
